# Help Desk

A full-stack IT support ticketing system built with React, Node.js, Express, and SQLite.

## Project goals

Help Desk gives employees a simple way to report technical issues and gives IT technicians a central dashboard for triaging, assigning, and resolving support tickets.

## Planned features

- Employee and technician accounts
- Secure authentication
- Ticket creation and status tracking
- Priority and category management
- Technician assignment
- Searchable ticket dashboard
- IT asset inventory
- Support analytics

## Technology

- **Frontend:** React and Vite
- **Backend:** Node.js and Express
- **Database:** SQLite
- **Authentication:** JSON Web Tokens and bcrypt

## Status

This project is under active development. The initial MVP focuses on authentication and ticket management.
